# Project instructions

This repository is the **documentation-only blueprint** for the application stack — the specification a
new project is built from. It contains no runnable code.

The normative rules live in
[`principles/DEVELOPMENT_PRINCIPLES.md`](principles/DEVELOPMENT_PRINCIPLES.md) and the workflow in
[`principles/WORKING_AGREEMENT.md`](principles/WORKING_AGREEMENT.md). Read both before scaffolding or
advising on any project built on this stack, then consult the area document relevant to your task.

[`CLAUDE.md`](CLAUDE.md) carries the same pointer plus the full document map, so both agent entry
points stay in sync without restating the rules. Start there for the map, or at
[`README.md`](README.md) for orientation and [`NEW_PROJECT_GUIDE.md`](NEW_PROJECT_GUIDE.md) to
bootstrap a project.
